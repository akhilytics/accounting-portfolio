# Accounting & Finance Work Samples

A collection of practical accounting and cost-analysis models I've built in Excel, using **illustrative (fictional) data** to demonstrate methodology. All names and figures are made up and do not represent any real company or client.

**Built by Akhila Nayak** — Accountant | R2R, MIS & Cost Analysis 

---

### How to use this repo
Each `.xlsx` file is a self-contained work sample. **Open the "About" tab** in any file for a full description of what it does, the methodology, and the skills it demonstrates.

Areas covered across these models include: project cost control & MIS, budget-vs-actual and variance analysis, accounts receivable (AR aging & collections), pricing & cost modelling, purchase price variance, RA billing & retention, cash-flow tracking, and advanced Excel.
